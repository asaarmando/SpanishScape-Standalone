# SpanishScape for macOS

## Download the app

1. Open the repository's **Actions** tab.
2. Choose **Build SpanishScape for macOS** and click **Run workflow** on the `main` branch.
3. When the run finishes, open it and download the **SpanishScape-macOS** artifact.
4. Unzip it, then open `SpanishScape.app`. If macOS blocks the unsigned app, Control-click it, choose **Open**, then confirm.

The repository builds the app on GitHub's macOS runner so you do not need to install Xcode or use Terminal. Builds are also attached to GitHub Releases for version tags beginning with `v`.
